# CineTEC

CineTEC is a web and mobile application for managing a cinema chain. Customers can browse movies, select seats, and purchase tickets, while administrators manage movies, branches, rooms, and screenings.

---

## 🚀 Features

### 🎟️ Client
- Browse movies in cartelera
- Select cinema and showtime
- Choose seats
- Purchase tickets
- Receive electronic invoice (XML + PDF)

### 👨‍💼 Admin
- Manage clients
- Manage movies
- Manage branches and rooms
- Configure screenings
